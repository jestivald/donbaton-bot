# ДонБатон: Wi-Fi и отдельные пакеты LTE

Кандидат форка на Bedolaga **v4.7.1**, upstream commit
`cd903b7cfd3bac6e08e571904662c88e8c151d1d`. Совместимый кабинет основан на
**v1.71.1**, commit `5ade78f506fd0e102d70e2d59af4aa97ef9c164b`.
Upstream LICENSE и история сохранены. В код перенесены действующие исправления:
email покупателя в чеке, LegalConsent в резервной копии, переключатель
административных уведомлений о нодах.

## Продукт и состояние

Цены новой сетки утверждены владельцем 09.09.2026 для подготовки запуска.
К существующим тарифам они автоматически не применяются. По умолчанию продажа
новых продуктов выключена до проверки серверов и переноса оплаченных остатков.
`docs/donbaton-catalog.json` содержит четыре **неактивных** предложения;
сквады в них не заполнены до проверки реальной топологии.

| Категория | Устройства | LTE каждые 30 дней | Цена за 30 дней |
|---|---:|---:|---:|
| Только Wi-Fi, Личный | 3 | — | 199 ₽ |
| Только Wi-Fi, Семейный | 7 | — | 299 ₽ |
| Wi-Fi + LTE, Личный | 3 | 60 ГиБ | 299 ₽ |
| Wi-Fi + LTE, Семейный | 7 | 120 ГиБ | 449 ₽ |

Докупки LTE: 20/60/120 ГиБ за 79/199/349 ₽, срок 30 суток.
Себестоимость провайдеров неизвестна. При полном использовании включённого LTE
доплата 100/150 ₽ покрывает лишь 1,67/1,25 ₽/ГиБ до комиссий и прибыли.
Годовые скидки прежних тарифов в новые предложения автоматически не переносятся.

Wi-Fi/LTE — названия групп серверов. Учёт не определяет тип сети телефона:
использование обходного сервера по Wi-Fi тоже расходует LTE-пакет.
1 ГиБ = 1 073 741 824 байта; считается upload + download, без коэффициента ×17.

## Правила

- Один пользователь панели и одна ссылка. Общий лимит панели равен нулю.
  При исчерпании LTE снимается только доступ к LTE-сквадам.
- Условия включённой квоты сохраняются на подписке. Изменение тарифной записи
  администратором не переписывает уже оплаченный лимит.
- Период — ровно 30 суток с первой активации. Досрочное продление сохраняет
  период и расход. Сброс текущего счётчика панели не выдаёт новый пакет.
- Докупка действует 30 суток с покупки, переживает обновление базового пакета
  и расходуется по ближайшей дате истечения. Она не продлевает подписку и
  не возобновляет административно отключённый или просроченный доступ.
- Мгновенная смена действующего тарифа с участием новых категорий закрыта.
  В течение срока можно продлить свой тариф или докупить LTE; другой тариф
  выбирается после окончания. Новая платная активация после окончания начинает
  новый период и сохраняет неистёкшие докупки.
- Пробные, подарочные, суточные, произвольные тарифы и новые подключения внешнего
  рекуррентного платежа для этих категорий не входят в текущий кандидат.
  Обычное продление текущего тарифа с баланса поддерживается.
- Старые тарифы имеют `network_category=NULL`. Автоматического переноса старых
  платных подписок в новый учёт нет: нужны сохранённые остатки, докупки и сроки.

## Включение на проверенном стенде

Миграция Alembic `0119` добавляет nullable поля категории и отдельные таблицы
`lte_quotas` / `lte_topups`. Старые строки не получают новую категорию.

```dotenv
DONBATON_LTE_ENABLED=false
DONBATON_LTE_ACCOUNTING_READY=false
DONBATON_WIFI_SQUAD_UUIDS=
DONBATON_LTE_SQUAD_UUIDS=
DONBATON_LTE_POLL_SECONDS=30
DONBATON_LTE_MAX_SAMPLE_AGE_SECONDS=180
```

Оба списка — UUID через запятую. Нужны непересекающиеся сквады **и inbound**.
`allowed_squads` каждого нового тарифа должен точно совпадать с WIFI либо
WIFI + LTE. Внешние сквады для этой политики запрещены.
`ACCOUNTING_READY` — явное подтверждение оператора после проверки WIFI=0/LTE=1
и согласованного переноса всех затронутых старых аккаунтов; это не автоматический
анализ нод. Менять общий множитель 17→1, оставив старые лимиты, нельзя.

До первого корректного lifetime-замера доступен Wi-Fi. Регресс счётчика,
другая личность panel-user или устаревший замер закрывают LTE до сверки.
Фоновый опрос следует запуску/остановке MonitoringService.
Сбор трафика, опрос и применение прав асинхронны: отключение не происходит
на последнем байте. При недоступности панели конечный перерасход не гарантируется.
Расход вокруг границы периода относится к предыдущему периоду первым успешным
замером; точность границы ограничена интервалом наблюдения.

## Проверки и выпуск

```sh
uv sync --frozen --group dev
uv run pytest -q tests/donbaton
# PostgreSQL должен быть отдельной тестовой БД: fixture пересоздаёт её схему.
TEST_DATABASE_URL=postgresql+asyncpg://test:test@localhost:5432/test \
  REQUIRE_POSTGRES_TESTS=1 uv run pytest -q tests/donbaton
```

Проверяются исчерпание LTE при работающем Wi-Fi, повторные события и покупки,
откат оплаты, реальная конкуренция PostgreSQL, продление, повторная активация,
границы периода, webhook, синхронизация, миграция и резервная копия.

Для production дополнительно требуется испытание малой квоты на обоих LTE-входах,
включая старые импортированные конфиги и уже открытые соединения; свежий снимок
оплаченных остатков старых клиентов; таблица переноса оплаченных прав.
Откат схемы удаляет новый ledger: после начала продаж требуется сначала сохранить
его и перенести приобретённые права. Простое `alembic downgrade` для работающего
нового биллинга не является безопасным откатом продукта.
